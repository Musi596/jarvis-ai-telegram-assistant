# 🤖 J.A.R.V.I.S. Telegram Bot

Telegram-бот с AI-ассистентом, вдохновлённым Джарвисом из вселенной Marvel. Бот отвечает на сообщения пользователя, используя большую языковую модель через **Groq API**, сохраняя фирменный стиль общения ассистента Тони Старка — сдержанный, вежливый, слегка ироничный и максимально полезный.

Построен на **aiogram 3** с полностью асинхронной архитектурой на Python.

---

## ✨ Возможности

- 💬 Общение с AI-ассистентом прямо в Telegram
- ⚡ Быстрые ответы благодаря Groq API (LLM-инференс на LPU)
- 🎭 Персонализированный стиль общения в духе J.A.R.V.I.S.
- 🔄 Полностью асинхронная обработка сообщений (aiogram + aiohttp)
- 🔐 Безопасное хранение токенов и ключей через `.env`

---

## 🛠 Технологии

- **Python 3.11+**
- **[aiogram 3](https://docs.aiogram.dev/)** — фреймворк для Telegram-ботов
- **[Groq](https://groq.com/)** — API для быстрого инференса LLM
- **python-dotenv** — управление переменными окружения
- **aiohttp / httpx** — асинхронные HTTP-запросы

---

## 📦 Установка

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/<ваш-username>/jarvis-telegram-bot.git
   cd jarvis-telegram-bot
   ```

2. **Создайте виртуальное окружение**

   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux / macOS
   venv\Scripts\activate         # Windows
   ```

3. **Установите зависимости**

   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения**

   Создайте файл `.env` в корне проекта:

   ```env
   BOT_TOKEN=your_telegram_bot_token
   GROQ_API_KEY=your_groq_api_key
   ```

---

## 🚀 Запуск

```bash
python main.py
```

После запуска бот начнёт принимать сообщения в Telegram и отвечать в стиле J.A.R.V.I.S., используя выбранную модель Groq.

## 📁 Структура проекта

```text
jarvis-telegram-bot/
│
├── main.py              # точка входа, запуск бота

```

## 🔒 Безопасность

Файл `.env` и виртуальное окружение исключены из репозитория через `.gitignore`:

```text
.env
venv/
__pycache__/
```

Никогда не публикуйте свои токены и API-ключи в открытом репозитории.
